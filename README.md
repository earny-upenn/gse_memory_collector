Memory Collector

Memory Collector is a simple browser-based game where you collect falling items that represent different types of campus memories.

How to Play
Move left and right to catch falling items
Books = academic moments
Coffee = study sessions
Caps = milestones
Cameras = campus memories
Collect as many as you can before time runs out

Controls
Desktop: Arrow keys
Mobile: On-screen buttons

Tech Stack
HTML
CSS
JavaScript
